# Documentation

This index points players to setup information and developers to the project
layout and technical guides.

## For players

- [Getting started](getting-started.md) — requirements, file preparation, and installation status.

## For developers

- [Port development](development/port.md) — build, test, provision, and publish the port.
- [Browser testing](development/browser-testing.md) — test conversion in Chromium and Firefox.
- [Architecture](development/architecture.md) — runtime files, relocation, and converter design.

## Project layout

- `src/` and `asset_construction/` contain shared game and asset source.
- `retro-go-sd/` contains the device port, SDK, release scripts, and browser page.
- `tools/` contains asset, converter, and test tooling.
- `docs/` contains player and developer guides.
