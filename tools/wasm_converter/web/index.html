SMG asset converter

A browser-based conversion path for Super Mario Galaxy (USA).

01 Source disc

Select the USA RMGE01 ISO. This stage checks its complete SHA-1 using the selected range size; the ISO is never copied into WASM memory or browser storage.

The selected size is allocated in WASM memory. Reading and copying each range temporarily needs a second buffer of similar size in the browser.

Waiting for an ISO.

02 Asset conversion

The converter reads the Wii partition through bounded file ranges and builds the final smg_assets.xip sidecar. The sidecar matches the native build; it is one component of the installable GWRG bundle.

Convert the ISO and download the generated asset pack
